## Verdict reasoning

This is category **(f) real and correctly stated**, and my independent checks make it stronger than
filed, not weaker.

**1. The construction pins the statistic.** `scripts/probes/_modeling_slim_panels.py:84-92` sets the
prediction's positive count equal to the truth's:

```python
# scripts/probes/_modeling_slim_panels.py:84-92
n_rich_truth = int((truth_eval["fractional_area"] >= FA_RICH_THRESHOLD).sum())
truth_eval["is_rich_truth"] = (truth_eval["fractional_area"] >= FA_RICH_THRESHOLD).astype(int)
truth_eval = truth_eval.sort_values("pred", ascending=False).reset_index(drop=True)
truth_eval["is_rich_pred"] = 0
if n_rich_truth > 0:
    truth_eval.loc[:n_rich_truth - 1, "is_rich_pred"] = 1
```

With `|A| = |B| = K`, `|A∩B| ∈ [max(0, 2K−n), K]`, so at K=523, n=656 the *worst* ranking still scores
390/523 = 74.6 % (attainable: only 133 poor tiles exist, so a maximally bad ranking puts all of them in
the top 523) and a random ranking scores `K²/n` = 417/523 = 79.7 % = the base rate. The quoted 91 % is
therefore 56 % of the way from chance to perfect, i.e. κ = 0.557.

**2. The claim is in the submitted artifact.** Confirmed by text extraction from
`docs/classification_slimmer.pdf` (page 8, §6 Conclusions) — not just in the markdown:

> "there *is* a CTX-recoverable signal — on the best images the model agrees with HiRISE truth on over
> 90 % of its rich-tile calls" — `docs/classification_slimmer.md:234-237`

**3. The asymmetry R61 rests on is exactly as described.** The same document supplies the chance
baseline for the panel where it hurts the model and omits it where it would cut the apparent skill by
four-fifths:

```
docs/classification_slimmer.md:202  pattern closely (476 of 523 rich-tile calls agree).*        <- no baseline
docs/classification_slimmer.md:206  the truth's green — only 20 of 129 rich-tile calls agree, well
docs/classification_slimmer.md:207  below the ~30 % a random ranking would produce at this base rate.*
```

and I confirmed the "~30 %" is arithmetically right (129²/439 = 29.4 %), so the author knew the
correction and applied it once.

**4. Two new aggravating facts.**
- *Cohort-wide the statistic is almost pure prevalence*: `Spearman(agree/K, base_rate) = +0.972`
  (p = 2e-22) across the 35 scorable folds, versus +0.410 against AUC. Pattern B is not an argument
  here, it is a measurement.
- *The plural "on the best images" sweeps in two near-chance images.* The only three images clearing
  90 % agreement are `ESP_053989_2260` (base 0.797, AUC 0.880, κ 0.557), `ESP_069763_2235` (base 0.969,
  agreement 97.1 %, **AUC 0.579, κ 0.035**) and `ESP_054622_2240` (base 0.993, agreement 99.3 %,
  **AUC 0.531, κ −0.007**). Two of the three "best images" by the quoted statistic have essentially no
  rank skill. The genuinely second-best image by AUC (`ESP_068483_2280`, AUC 0.872) scores 89.9 % —
  just *under* the threshold the sentence uses.

**5. The project's own internal record is more conservative than the external report.**
`DECISIONS.md:2415-2419` records the intended framing as "real but small ranking signal, per-tile
boulder-rich classification **not tractable** at CTX resolution". The ">90 % agreement" sentence is
a drift away from that, not an expression of it. So verdict (c) does not apply: nothing in `DECISIONS.md`
or the writeup discloses the chance baseline for this statistic (grep for `rich-tile calls` → only
these two docs; the one κ-style correction in the record, `DECISIONS.md:2763`'s "89.8 %", is the

## Fix assessment

The register's fix ("quote the agreement against its chance baseline, or use κ") is correct and
sufficient, and per Brian's 2026-08-03 remedy ruling it is discharged by a caveat header rather than a
recomputation. Two refinements:

- **Use the exact numbers, they are already derived:** "476 of 523 (91 %), against 417 (80 %) expected
  from the base rate alone and a floor of 390 (75 %) — κ = 0.56". Because K is matched to the truth
  count, `agree/K` *is* precision = recall = F1, and κ for equal marginals equals the
  random-to-perfect skill fraction exactly (I verified both are 0.5568), so κ = 0.56 is the single
  number that says it all.
- **Fix the plural too.** The caveat bullet should read something like: *"R61 — the '>90 % agreement'
  claim is ~10 points above chance at this image's 80 % base rate (κ = 0.56); cohort-wide this
  agreement statistic correlates +0.97 with the per-image base rate, and two of the three images that
  clear 90 % have AUC ≤ 0.58."* Otherwise a future reader repairs the number and leaves the "best
  images" framing, which is the part that is actually false.
- The producer itself needs no change; if it is ever re-run, adding `rand={K*K/n:.0f}` to the panel
  title at `_modeling_slim_panels.py:131-135` would make the omission impossible to repeat.
